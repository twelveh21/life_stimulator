# 《人生未选择》提交说明

## 作品本体

本包为可运行的本地网页项目。解压后进入项目目录，执行：

```powershell
npm start
```

浏览器打开 `http://localhost:4173` 即可体验。

详细配置与模型密钥说明见根目录 `README.md`。项目默认可使用本地备用叙事；如配置千问或 OpenAI 兼容密钥，场景会实时生成。

## 展示内容

- `图文教程.md`：约 1788 字，含标题、开头钩子、玩法说明、搭建步骤、效果展示与复盘。
- `创作说明.md`：281 字，符合 300 字以内要求。

教程配图使用项目内电影场景素材，位于 `public/assets/`。为保护本地密钥，交付包不包含 `.env` 文件。
