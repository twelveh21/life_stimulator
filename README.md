# 《人生未选择》

MIT License · v0.2

[在线试玩 Demo](https://life-unchosen.onrender.com) · [图文教程](submission/图文教程.md) · [创作说明](submission/创作说明.md)

一个无需构建步骤的 AI 互动叙事 Web 应用。它从用户填写的过去分岔点出发，先规划约 12 个跨学业/工作、关系、财务和生活领域的人生节点，再根据每次选择实时生成下一幕。实际幕数以模型返回的主线计划为准。

## 启动

在此目录运行：

```powershell
npm start
```

然后访问 `http://localhost:4173`。

## 已实现

- 真实人生档案与本地存档
- 分岔点文本解析、可编辑确认与终章年龄校验
- 12 幕因果相连的人生主线（幕数以模型主线计划为准），包含预设和自由输入选择
- 千问/兼容模型服务端调用：每次选择后生成下一幕，密钥不进入浏览器
- 状态快照回溯：旧分支保留，新分支不会带入未来事件
- 未来自我上下文对话与 SVG 分享海报下载
- 移动端布局、转场、错误处理与清空存档

## 模型服务（可选）

本项目要求模型服务可用：复制 `.env.example` 为 `.env` 后配置 `DASHSCOPE_API_KEY`（千问），重启服务即可。每一幕主线、选择后的续写及未来自我对话都由服务端调用千问生成；若模型不可用，界面会明确提示并允许重试，不会降级为本地剧本。密钥不会发送到浏览器，也不应写入前端文件或提交到仓库。

提交材料位于 `submission/`：图文教程、创作说明和提交说明均可直接查看。

## Render 部署

仓库已提供 `Dockerfile` 与 `render.yaml`。在 Render 中选择 **New + → Blueprint**，连接本仓库后填入私密环境变量 `DASHSCOPE_API_KEY`，即可部署。不要把密钥提交到 GitHub。

### 部署后“模型无法调用”的自查

1. 打开 `https://<你的域名>/api/health`，应返回 `{"ok":true,"aiConfigured":true,"provider":"qwen"}`。若 `aiConfigured` 为 `false`，说明 Render 的环境变量里没有 `DASHSCOPE_API_KEY`（`render.yaml` 中该变量是 `sync: false`，需要在 Render 控制台手动填一次）。
2. Render 免费实例 15 分钟无访问会休眠，第一个打开链接的人需要等 30–60 秒唤醒。前端“正在生成下一幕”已提示这一点，失败时可点“重试生成”。
3. 健康检查正常但仍生成失败时，查看 Render 的 **Logs**：服务端会打印 `[ai] 时间 上游状态 错误`，可据此区分密钥无效（401/403）、限流（429）、超时（504）或网络失败（502）。
4. 免费实例可加一个 uptime 监控（如 cron-job.org）每 10 分钟访问一次 `/api/health`，避免冷启动影响分享链接的体验。
5. 单次模型调用默认超时 90 秒，可用环境变量 `AI_TIMEOUT_MS` 调整；前端单次请求上限 120 秒。
