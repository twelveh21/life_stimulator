# 《人生未选择》

MIT License · v0.2

一个无需构建步骤的 AI 互动叙事 Web 应用。它从用户填写的过去分岔点出发，先规划 8 个跨学业/工作、关系、财务和生活领域的人生节点，再根据每次选择实时生成下一幕。

## 启动

在此目录运行：

```powershell
npm start
```

然后访问 `http://localhost:4173`。

## 已实现

- 真实人生档案与本地存档
- 分岔点文本解析、可编辑确认与终章年龄校验
- 8 幕因果相连的人生主线，包含预设和自由输入选择
- 千问/兼容模型服务端调用：每次选择后生成下一幕，密钥不进入浏览器
- 状态快照回溯：旧分支保留，新分支不会带入未来事件
- 未来自我上下文对话与 SVG 分享海报下载
- 移动端布局、转场、错误处理与清空存档

## 模型服务（可选）

本项目要求模型服务可用：复制 `.env.example` 为 `.env` 后配置 `DASHSCOPE_API_KEY`（千问），重启服务即可。每一幕主线、选择后的续写及未来自我对话都由服务端调用千问生成；若模型不可用，界面会明确提示并允许重试，不会降级为本地剧本。密钥不会发送到浏览器，也不应写入前端文件或提交到仓库。

提交材料位于 `submission/`：图文教程、创作说明和提交说明均可直接查看。
